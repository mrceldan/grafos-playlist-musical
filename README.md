# 🎵 Playlist Musical — Representação de Grafos

Repositório desenvolvido para a disciplina **Estrutura de Dados**, na modalidade **Aula Invertida**.

O projeto tem como objetivo demonstrar, na prática, como os **grafos** podem ser aplicados através de uma **playlist musical interativa**.  
Cada **música** é representada como um **nó (vértice)** e as conexões entre músicas representam as **arestas** do grafo, permitindo **interação com o usuário** e **sugestão de faixas relacionadas**.

---

## 🎯 Objetivo

Aplicar conceitos de **Estrutura de Dados** utilizando **Java**, com foco na **implementação e manipulação de grafos**, explorando funcionalidades inspiradas em uma playlist musical, como:

- Execução aleatória
- Sugestão de músicas relacionadas
- Avançar e retroceder músicas na playlist

---

## 🧠 Conceitos Utilizados

- Estruturas de **grafos genéricos**, com suporte a relações **direcionadas** e **não direcionadas**.  
- Representação por **lista de adjacência**, garantindo eficiência nas operações de **busca** e **inserção**.  
- Manipulação dinâmica de **vértices (músicas)** e **arestas (relações entre faixas)**.  
- Utilização das conexões diretas no grafo para **sugerir músicas relacionadas** e **navegar entre faixas**.
